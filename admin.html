Sign in with your GitHub access key to edit and publish your portfolio.

How do I get an access token?
  1. Open GitHub → New fine-grained token.
  2. Name it Portfolio admin and pick an expiry (e.g. 1 year).
  3. Under Repository access, choose Only select repositories and pick your website repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it above.

The token stays in this browser only. It can only change that one repository, and you can revoke it on GitHub any time.
